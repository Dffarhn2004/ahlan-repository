# 06 — Staf dan peninjau

Menu kiri Anda sama dengan menu admin. Perbedaan ada pada tindakan yang server izinkan. Jika suatu tombol tetap terlihat lalu gagal, itu sesuai aplikasi hari ini: menu tidak disembunyikan per peran.

## Staf

Anda dapat:

- membuka dashboard, profil, daftar dokumen, status kanal, sumber web, dan percakapan pesantren Anda,
- membuat folder, mengunggah dokumen, dan mengganti isi atau nama berkas,
- menekan **Perbarui pengetahuan asisten**,
- membaca percakapan Telegram, menindaklanjuti statusnya, dan mengekspor Excel,
- memuat ulang halaman yang sama.

Anda tidak dapat:

- menghapus dokumen,
- mengubah profil, logo, tautan, atau kontak,
- menghubungkan, mengganti, atau melepas Telegram dan WhatsApp,
- menyiapkan, mengaktifkan, atau menonaktifkan asisten,
- menambah pengguna atau mengubah peran,
- membaca **Aktivitas sistem**,
- menambah atau menjalankan sumber web, serta menyunting hasil pengambilannya.

Pada **Pengguna**, halaman menampilkan: *Anda tidak memiliki izin untuk mengelola pengguna.*

## Peninjau

Anda dapat membaca data pesantren sendiri: profil, dokumen, status bot, daftar sumber web, dan hasil halaman yang sudah diambil.

Anda tidak dapat mengunggah, mengganti, menghapus, menyinkronkan pengetahuan, mengubah percakapan, mengubah kanal, atau membuka jejak aktivitas.

Gunakan peran ini untuk orang yang perlu memeriksa isi tanpa mengubahnya.

## Keduanya

- Anda hanya melihat pesantren tempat akun Anda terdaftar.
- Token bot tidak pernah tampil.
- Halaman publik `/p/{slug}` tetap bisa dibuka tanpa peran khusus.
- Mengobrol dengan bot mengikuti mode kanal. Akun dashboard tidak otomatis menjadi penguji Telegram atau WhatsApp. ID atau nomor Anda harus ada di daftar uji, atau kanal harus berstatus publik.
